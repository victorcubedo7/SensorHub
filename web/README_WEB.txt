SENSORHUB WEB
=============

Version: v0.0.1.17102026
Estado: prototipo inicial

DESCRIPCION
-----------
Pagina web sencilla con un menu lateral desplegable. La interfaz esta
implementada con HTML, CSS y JavaScript, sin dependencias externas.

FUNCIONALIDADES IMPLEMENTADAS
-----------------------------
- Boton de menu con icono de hamburguesa (☰).
- Al pulsar el boton, se muestra u oculta el menu lateral.
- El icono cambia a una flecha (←) cuando el menu esta abierto.
- El boton cambia de posicion y aspecto al abrir el menu.
- El menu contiene las opciones Home, Ajustes, Opcion 1 y Opcion 2.
- Los enlaces se muestran centrados en rectangulos con fondo naranja,
  borde negro y esquinas redondeadas.
- El boton y el menu tienen estilos definidos para su posicion, tamano,
  colores y orden de superposicion.

ESTRUCTURA
----------
- home.html: estructura de la pagina, boton y opciones del menu.
- css/Home.css: estilos del boton, panel lateral, enlaces y pagina.
- js/sidebar_menu.js: comportamiento para abrir y cerrar el menu.

USO
---
Abre web/home.html en un navegador y pulsa el boton ☰ para desplegar o
cerrar el menu.

LIMITACIONES ACTUALES
---------------------
- Los enlaces usan destinos de ejemplo ("###"); todavia no llevan a
  paginas o funcionalidades reales.
- Las opciones Home, Ajustes, Opcion 1 y Opcion 2 son elementos visuales
  del prototipo.
- El diseno esta en desarrollo y puede necesitar ajustes entre movil y PC.
